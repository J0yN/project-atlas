# Project Atlas v1.0.0

## Highlights

- Production-ready internationalized App Router foundation
- Dashboard workspace for projects, articles, analytics, and settings
- Strict TypeScript, CSS Modules, and server-first architecture
- Launch documentation covering deployment and QA

## Included in this release

- Localized routing with middleware-based locale detection
- Typed dictionary loading and SEO metadata support
- Dashboard information architecture and theming controls
- Production verification workflow: install, typecheck, lint, build

## Operational notes

- Set `NEXT_PUBLIC_SITE_URL` in the production environment before deployment.
- Publish the GitHub Release from tag `v1.0.0`.
- Run the QA checklist before announcing the release externally.
