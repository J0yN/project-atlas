# social images

Purpose

Assets intended for social previews and cards (Open Graph, Twitter cards).

Conventions

- Create dedicated images for social sharing: recommended sizes (e.g., `og: 1200x630`, `twitter: 1200x675`).
- Filenames: social-<context>-1200x630.png or social-<context>-1200x675.webp
- Keep imagery simple and legible at thumbnail sizes.
