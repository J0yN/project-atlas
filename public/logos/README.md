# logos

Purpose

Store production-ready logo assets for the brand: SVGs and exported raster variants for different contexts (light/dark, square/horizontal).

Conventions

- Filenames: logo-<variant>-<purpose> e.g., logo-mark.svg, logo-horizontal-light.png
- Keep vector SVGs as the primary source; rasterize only for specific delivery needs.
- Maintain a brief manifest describing intended usage and color variants.
