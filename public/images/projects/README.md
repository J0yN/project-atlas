# projects images

Purpose

Contains production images for projects (listings, detail hero images, thumbnails, and gallery assets).

Conventions

- Filenames: project-<slug>-<purpose>-<width>x<height>.<ext> e.g., project-atlas-hero-1600x900.webp
- Provide responsive variants and consider aspect-ratio consistency between thumbnails and hero images.
- Compress and strip metadata for photos.
