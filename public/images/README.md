# public images

Top-level container for all image assets used on the public site. This folder groups images by purpose (projects, journal entries, workspace screenshots, user avatars, illustrations, and placeholders).

Guidelines

- Store only production-ready, optimized image files here (WebP/AVIF/JPEG/PNG/SVG).
- Use responsive image techniques (srcset, sizes) and provide @1x/@2x variants when appropriate.
- Follow the naming conventions described in the root README (kebab-case, descriptive, include size when helpful).
- Keep originals and design source files outside this tree.

Examples of subfolders:
- projects/ — hero and thumbnail images for project listings and detail pages.
- journal/ — article header images and inline media for the project journal.
- workspace/ — screenshots and UI imagery related to workspace features.
- avatars/ — user profile pictures and system avatars.
- illustrations/ — composed illustrations (exported SVG/PNG/WebP).
- placeholders/ — low-fidelity placeholders and blurred preview images.
